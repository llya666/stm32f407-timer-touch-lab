# STM32F407 定时器与触摸屏综合实验（2026 创新实验室招新选拔 · 软件第二题）

基于 **STM32F407ZGT6 + 标准外设库（SPL）** 的定时器与触摸屏界面实现，覆盖 PWM 输出、双通道相位、
输入捕获测频率/占空比、自动扫频自检、SPWM 正弦、秒表、贪吃蛇（含自动通关）共 15 项考核。

- 屏幕：**竖屏 240×320**（`LCD_Display_Dir(0)`）
- 触摸：**四点半自动校准 + 二维仿射映射**，系数掉电保存在 24C02
- 主频 168MHz，APB1 = 42MHz，**定时器时钟 84MHz**（F4 规则：APB1 分频 ≠1 时 ×2）

---

## 一、引脚分配

| 功能 | 引脚 | 定时器 | 说明 |
|---|---|---|---|
| PWM 主输出 / SPWM 输出 | **PA6** | TIM3_CH1 | 两个功能复用同一个脚 |
| PWM 第二路（相位） | **PA7** | TIM3_CH2 | 板子没引出时用下面两个 |
| PWM 第二路（备用） | **PB5 / PC7** | TIM3_CH2 | 三个脚同时输出，**引出哪个测哪个** |
| 输入捕获输入 | **PB6** | TIM4_CH1 | **只需接这一个脚** |
| 输入捕获（内部） | — | TIM4_CH2 | 间接通道，借 TI1 捕获下降沿 |
| 秒表时基 / 全局心跳 | — | TIM6 | 1ms 中断 |
| 触摸屏 | PB0/PB1/PB2/PC13/PF11 | — | 厂商驱动 |
| 24C02（EEPROM） | PB8 / PB9 | 软件 I²C | 存触摸校准系数 |
| LCD | FSMC（PD/PE 系列） | — | 厂商驱动 |

> **注意**：PA6/PA7/PB5/PC7 在本工程中只被 PWM 使用，无冲突。

## 二、三种自测接法（不需要任何外部仪器）

### 1. PWM / 相位 —— 示波器接 PA6
```
示波器 CH1 探头 → PA6      地夹 → GND
示波器 CH2 探头 → PA7 / PB5 / PC7（看相位时用）  地夹 → GND
```

### 2. 输入捕获 / 自动扫频 —— 一根杜邦线
```
PA6 ●────────● PB6
```
同一块板子天然共地，不需要拉地线。进 `Capture` 页或 `Sweep` 页点 `RUN` 即可。

### 3. SPWM —— 需要 RC 低通
```
PA6 ──[10kΩ]──●──→ 示波器探头尖
              │
            [100nF / 104]        （电解电容：长脚正极接节点，短脚负极接 GND）
              │
             GND ──→ 示波器地夹
```
探头**必须夹在电阻和电容之间的节点**，不能夹 PA6。
RC 取值满足 **R × C ≈ 1ms**（转折频率 159Hz）即可，例如 1kΩ+1µF、10kΩ+100nF、
2kΩ+470nF、100Ω+10µF。

## 四、关键原理速查

| 项目 | 公式 / 要点 |
|---|---|
| PWM 频率 | `f = 84MHz / ((PSC+1) × (ARR+1))` |
| PWM 占空比 | `duty = CCR / (ARR+1) × 100%` |
| 测频 | `f_in = 84MHz / period`（period 为两次上升沿的计数差） |
| 测占空比 | `duty = pulse / period × 100%` |
| 相位 | `CCR2 = phase/360 × 周期`；CH2 占空比 = `100% − 相位`（单定时器的取舍） |
| SPWM 正弦频率 | `f_sine = 载波 / 采样点 = 20kHz / 400 = 50Hz` |
| RC 转折频率 | `fc = 1/(2πRC)`，取 `RC ≈ 1ms` → 159Hz |
| 触摸映射 | `screen = a·rawX + b·rawY + c`（六系数解轴交叉/镜像/偏移/比例） |

### 几个容易踩的坑（本工程已处理）

1. **`delay_init` 在 `SYSTEM_SUPPORT_OS=0` 时不会开 SysTick 中断**，所以全局心跳 `g_tick`
   必须由 TIM6 的 1ms 中断提供，不能依赖 `delay_ms` 的 SysTick。
2. **`LCD_ShowString` 用全局 `BACK_COLOR` 填字符背景**，每次写文字都必须同时设前景和背景色，
   否则会继承上一次的深色 → 出现"黑底黑字"。
3. **输入捕获 CH2 要用 `TIM_ICSelection_IndirectTI`**，否则 CH2 只认 PB7，
   单接 PB6 时占空比永远读不到（表现为一直 `No Signal`）。
4. **SPWM 会把 CH2 输出关掉**（`CCER &= ~CC2E`），所以 `PWM_Set` 里会先把 CH2 重新使能，
   并且 `draw_pwm()` 进页时会按当前参数重配一次两路输出。
5. **500kHz 时一个周期只有 168 个计数**，占空比必须四舍五入（`(duty*period+50)/100`），
   否则 10% 档会算出 9.52%，误差 4.8% 超指标。
6. **滑条缩小绿段时要涂到旧的右端**（`xn+1 .. xo`），少算一列就会在旧位置留一条竖线。

```
src/
├── USER/
│   └── main.c        系统初始化、触摸仿射校准、主循环
└── APP/
    ├── app.c/.h      定时器业务：PWM / SPWM / 输入捕获 / 秒表
    ├── menu.c/.h     界面与触摸派发：7 个页面 + 键盘 + 滑条
    └── game.c/.h     贪吃蛇：哈密顿回路 + 自动通关
```

本仓库只包含**自己写的部分**。编译还需要厂商例程里的
`FWLIB`（标准外设库）、`CORE`（启动文件）、`SYSTEM`（delay/sys/usart）、
`HARDWARE`（tftlcd/touch/24cxx/led）四个目录。

### 接入 Keil 工程

1. 用厂商的 SPL 例程模板新建工程（或直接用本工程的 `第二题例程.uvprojx`）
2. 把 `APP` 目录添加到工程（Source Group），并在 **Include Paths** 里加入 `..\APP`
3. 需要外设时钟/中断配置：`TIM3`（PWM/SPWM）、`TIM4`（捕获）、`TIM6`（秒表）
4. `F7` **Rebuild All**（不是 Build），`F8` 下载

> 头文件路径里 `..\APP` 这一项很容易漏，漏了会报
> `cannot open source input file "app.h"`。

## 六、使用说明（屏幕操作）

### 主菜单
六个模块：`PWM` `StopWatch` `Capture` `Sweep` `SPWM` `Snake`。
点卡片**任意位置**都能进（按最近中心吸附，无死区）。子页右上角 `BACK` 返回。

### PWM Output
- `FREQ` / `DUTY` / `PHASE` 点开 3×4 键盘输入，`OK` 确认、`<` 删一位、点上方空白取消
- 频率范围 1~500000 Hz；超过 200kHz 时占空比自动吸附到 5% 一档
- 底部滑条按住左右拖动可连续改占空比

### Stopwatch
`START` 开始 / 暂停，`LAP` 计圈（最多 10 圈，屏幕上按顺序列出"本圈用时 + 累计"），
`RESET` 清零。

### Input Capture
进页即测，显示 `Freq` 和 `Duty`；无信号显示 `No Signal`（1 秒无有效读数才判定）。

### Sweep
点 `RUN` 自动跑 10 个频点（10Hz ~ 200kHz），逐行显示
`No / Set Hz / Get Hz / Err %`，任何一点误差 >1% 判 `FAIL`。

### SPWM
点 `START` 输出 20kHz 载波调制的 50Hz 正弦（占空比 5%~95% 扫描），
页面实时显示 `Duty 5~95% running`；点 `STOP` 或 `BACK` 停止。

### Snake
点棋盘上下左右转向，底部 `NEW` 重开 / `AUTO` 自动模式 / `SPEED` 变速 / `PAUSE` 暂停。
自动模式用哈密顿回路 + 抄近路，能自己吃满 440 格通关。

## 七、触摸校准说明

- 上电时若 24C02 里没有有效系数，会自动进入四点校准（屏幕出现红十字）
- 校准点故意**往屏幕里收**（`(30,40) (210,40) (30,280) (210,280)`），
  不贴边 —— 手指贴边压不准，校出来的系数会偏，导致下半屏点不中
- 四点解 6 系数后做残差校验，≤20px 才收工；不合格最多重试 12 轮，取最优解保存
- 系数存在 24C02 的 220~243 号（×10⁷ 存成整数），251 号写 `0xCA` 作为"已校准"标记

## 八、调试记录（踩过的坑）

| 现象 | 根因 | 处理 |
|---|---|---|
| 白屏 | PLLM 与晶振不匹配 | 换回 SPL 例程并核对时钟树 |
| 文字变黑 | 离开贪吃蛇后 `BACK_COLOR` 仍是深色 | 每次写文字显式设前景/背景色 |
| 贪吃蛇冻结 | `delay_init` 非 OS 分支不开 SysTick 中断 | 全局心跳改由 TIM6 提供 |
| 捕获一直 `No Signal` | CH2 用了 DirectTI，只认 PB7 | 改成 `IndirectTI` 借 TI1 |
| 改频率后捕获不更新 | 多周期累加器混着旧数据 | `PWM_Set` 末尾调用 `IC_Resync()` |
| 拖动滑条留竖线 | 缩小绿段时漏掉旧右端那一列 | 填充区间改成 `xn+1 .. xo` |
| 下半屏点不中 | 校准点贴边，系数被压歪 | 校准点往里收 |
| 0% 显示高电平 | 探头地夹夹在信号脚上（测量反向） | 地夹必须夹 GND |
